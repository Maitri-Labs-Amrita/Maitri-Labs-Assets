## 2. What background will it sit on?

Every shape folder (`mark/`, `lockup/`, `stacked/`) has the same 4 subfolders:

| Subfolder | The logo colours are for… | Background in the file |
|---|---|---|
| `light-transparent/` | a **white or light** page | none (see-through) |
| `dark-transparent/` | a **navy or dark** page | none (see-through) |
| `light-filled/` | anywhere | solid **white** box |
| `dark-filled/` | anywhere | solid **navy** box (`#011A42`) |

- **"light" / "dark"** = the colour of the page the logo goes on, not the colour of the logo.
- **"transparent"** = no background. The page shows through.
- **"filled"** = the logo comes in its own coloured box.

Not sure? Pick `light-transparent` for documents and slides with a white background.

## 3. Which file?

Each subfolder has 4 files:

| File | When |
|---|---|
| `.svg` | First choice. Sharp at any size. Works in Figma, PowerPoint, Google Slides, web. |
| `-512w.png` | Small uses: email, chat, documents. |
| `-1024w.png` | Slides, web pages. |
| `-2048w.png` | Print, posters. |

`512w` means 512 pixels wide.
